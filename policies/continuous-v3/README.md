# Methods from continuous search

These Method v3 versions were made from game feedback. Each folder is immutable after validation and contains its parent, hypothesis, input trials, source, and hashes. Failed versions remain here.

The fixed validator and development maps did not change. These are supplied-kit production tests, not rocket launches. See the [reviewed results](../../evidence/continuous-policy-search-2026-09-10/README.md).
